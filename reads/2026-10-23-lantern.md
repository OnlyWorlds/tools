# Lantern, read 2026-10-23

Read against the seven lines by the OnlyWorlds maintainer (Kael), at [lantern `725da67`](https://github.com/OnlyWorlds/lantern/tree/725da67) and at https://lantern.onlyworlds.com, signed out. Lantern is the crew's own tool, so it was read directly rather than through the form. File references are at that commit.

1. **It is what it says.** The URL serves Lantern; the source is public under MIT, with a NOTICE for the name and look.
2. **Keys stay with the person.** The world key and the account token are stored in the phone's IndexedDB (`src/db.ts`, `src/account.ts`), the PIN in its localStorage (`src/pin.ts:17,25`). Nothing is stored on Lantern's host, which serves static files only.
3. **It names itself.** Every SDK client it makes passes `client: 'lantern'` (`src/world.ts:32`), so its writes carry `X-OW-Client: lantern`. A world born on the phone gets the producer line `{tool: "lantern", version: <build id>, input: "bare"}` (`src/worldfile.ts:55-58`); a world opened from a file keeps that file's own line. It has no fields of its own, so no prefix.
4. **It speaks the wire.** Every call goes through `@onlyworlds/sdk` (4.68.0); the one other `fetch` is to its own `/version.json` (`src/app-state.ts:57`). It writes no folder. Its world file is the SDK's `writeWorldFile`, and its production walk reads the saved file back through `readWorldFile`.
5. **What leaves the machine.** A world on the phone stays there; a world online syncs its elements with www.onlyworlds.com and images with upload.onlyworlds.com, and Ask and Sort send the elements the phone's own lookup found, as text, to onlyworlds.com (`/account/ask`, `/account/sort`), never to a model host. An element's picture is fetched from its `image_url` with a plain GET, no key.
6. **The host.** 200 over HTTPS with HSTS (max-age 31536000); http redirects to https; certificate CN=lantern.onlyworlds.com, valid to 2027-01-12. The page loads only from its own origin. Its CSP allows connections only to itself, www.onlyworlds.com and upload.onlyworlds.com.
7. **Its core is open and free.** Holding, searching, editing and playing worlds needs no account. Sync, Ask and Sort need a free onlyworlds.com account (its sign-up asks for an email, a username and a password, no invite and no payment); Ask and Sort draw on a daily allowance, with no payment path in the code.
